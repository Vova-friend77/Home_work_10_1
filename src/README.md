
# Проект Homework_10_1

## Описание:
   Данный проект - это веб-приложение на Python, позволяет сортировать
   банковские операции клиента по указанному параметру
   
## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/Vova-friend77/Home_work_10_1.git
```
2. Установите зависимости:
```
 pip install -r requirements.txt
```
## Использование:
1. Откройте приложение в вашем веб-браузере.
2. Введите банковские операции клиента за интересуемый период.
3. Укажите параметр для сортировки карт: EXECUTED/ CANCELED
4. Вызовите функцию filter_by_state.
5. Использование функции sort_by_date позволяет сортировать
   операции клиента по дате.

## Пример выполнения функции filter_by_state:
[{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
